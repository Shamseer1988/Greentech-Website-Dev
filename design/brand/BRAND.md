# Green Tech – Brand guide (APPROVED: current logo)

Approved by management: the **current Green Tech logo** (green crescent + rose outline emblem,
"GREEN TECH / REAL ESTATE BROKER" + "جرين تك / للوساطة العقارية"), redrawn as clean vector.
The Twin Crescent redesign is kept for reference only in `design/brand-alternative-twin-crescent/` – do not use it on the website.

## Logo files (`svg/` – text outlined, no fonts needed · `png/` – transparent)
| Need | File |
|---|---|
| Full bilingual logo (letterhead, signboard, About page, print) | `greentech-logo-horizontal.svg` |
| **Website header (English site)** | `greentech-logo-compact-en.svg` · on dark hero: `greentech-logo-compact-en-on-dark.svg` |
| **Website header (Arabic site)** | `greentech-logo-compact-ar.svg` · `-on-dark.svg` |
| Footer, social posts, flyers | `greentech-logo-stacked.svg` · `-on-dark.svg` |
| Emblem only (loading, map pins, watermark) | `greentech-emblem.svg` · `-on-dark.svg` |
| One colour (stamp, fax, emboss) | `*-mono-dark.svg`, `*-mono-white.svg` |
| Instagram / Facebook / WhatsApp profile picture | `png/greentech-app-icon-1024.png` (white) or `greentech-app-icon-dark-1024.png` |
| Link preview when shared | `png/og-image-1200x630.png` (white) or `og-image-dark-1200x630.png` |
| Browser tab / phone home screen | `favicon/` → `favicon.ico`, `favicon.svg`, `apple-touch-icon.png`, `android-chrome-*.png` |

Rules: keep clear space = the crescent's height on all sides · minimum width: horizontal 240 px, compact 140 px, emblem 24 px ·
on photos or dark backgrounds use the `-on-dark` or `-mono-white` version · never stretch or recolour.
